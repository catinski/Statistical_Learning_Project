# Statistical Learning Project
In this repository one can find all the material related to the exam project of the course of Statistical Learning. The project is based on the application of different Statistical Learning methods on a dataset containing health related data associated with the smoking behavior of individuals. 
The project is structured by providing a brief Exploratory Data Analysis (EDA), followed by the application of unsupervised learning methods, such as PCA and clustering, and the application of supervised learning methods, such as the Generalized Linear Model (GLM), the Lasso Regression, and the Decision Trees.
The dataset used is available on Kaggle at the following link: https://www.kaggle.com/datasets/gauravduttakiit/smoker-status-prediction/data.
